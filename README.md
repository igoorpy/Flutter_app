
# Laboratório 3 - Desenvolvimento Mobile

Projeto de uma Calculadora funcional desenvolvida em Flutter (`lib/main.dart`).

## Nota sobre o Ambiente
Devido a limitações de hardware e virtualização (KVM) no emulador Android no Linux Mint, a aplicação foi configurada para rodar nativamente via Linux Desktop (`flutter run -d linux`), garantindo execução leve e testes em tempo real.

## Como Executar
```bash
flutter run -d linux
